## Preserve the source

Original files retain their captured bytes, including historical formatting and README counts. They are excluded from formatting and Markdown lint. Current authored indexes and this inventory remain checked. The documentation reader does not index or build original snapshot Markdown as current project guidance.

A later source change needs a new dated snapshot and a written comparison. Never overwrite this capture to absorb source edits, formatting changes or new release decisions. The [documentation handoff](../features/setup/docs-implementation.md) describes capture evidence and verification.
